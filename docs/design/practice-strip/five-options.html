练习条 · 画线风五案

位置:tab header 与正文之间的一条水平带。三种状态:静默(无进行中的练习,几乎不可见)、 展开(点开后露出「凯格尔 / 番茄 / 补录」三个入口)、运行(显示当前相位与进度)。 凯格尔节律统一示意为「收 10″ / 放 5″ × 20」,番茄示意为「学习 · 25′」。 动画按真实节律循环(15 秒一循环),静态截图请以文字标注为准。

案一 · 隐线 基线即界面,不新增任何面

练习条不占一条带,它就住在 tab header 已有的那条基线上。静默时是基线中央一小段略粗的墨; 运行凯格尔时这段墨随「收」慢慢生长、随「放」退回——肌肉的收放直接画在线上; 番茄则是基线从左向右着墨。整案零新增高度,是五案里最克制的一个。

案二 · 夹条 账本里探出的小纸条,正字计数

一张从 header 下探出头的小纸条,像账本里夹着的便签——不通栏,只占它需要的宽度。 静默时报今日小计;展开成一张带装订红线的迷你账页;运行凯格尔时,完成的次数用「正」字 一笔一笔写出来(每五次一个正,正在做的那个字只写了一半)。

案三 · 刻度 时间是一段被丈量的距离

整条是一把通栏的细刻度尺。番茄 25 分钟 = 25 格,凯格尔 20 次 = 20 格(每 5 格一根长刻), 走过的格子着墨,一枚制图青的针标出当下。展开时,三个入口像尺上的三个站点。 它是五案里唯一把「总量和剩余」画成空间的——一眼看出走到哪、还剩多远。

案四 · 息线 一根会呼吸的墨线

整条只有一根手绘感的墨线。静默时几乎是平的;展开时线向下松开一个「口袋」,入口藏在袋里; 运行凯格尔时,线的中段随「收」隆起、随「放」落平——这根线就是你的肌肉,收放节律直接可见, 不需要任何数字也能跟上节奏。它是给凯格尔体验做到极致的一案。

案五 · 眉批 纯文字,书页上的批注

没有任何图形——整条是一行宋体批注,像书页天头上的眉批。展开是一句可点的话, 运行时是一句会计数的话:相位字「收 / 放」放大领起,进度是这句话下面那条慢慢写长的底线。 给喜欢把界面当排版做的人;实现也最便宜,一个 flex 一行字。
