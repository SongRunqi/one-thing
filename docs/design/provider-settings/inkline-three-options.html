Provider 设置页 · 三个重构方案

三案共同解决的旧问题:模型名/状态重复出现三处;单列手风琴展开把页面无限拉长;Configure/Edit/整行点击三种入口混在一行;Temperature 和 Max Output 与模型脱节。三案的信息架构截然不同:案一按「provider 工作台」组织,案二按「总览 → 专注」两级组织,案三直接翻转为「模型优先」。

案一

工作台 · 左右主从

左侧细栏是唯一的 provider 索引(已连接/未连接分组,★ 标默认);右侧整个工作区属于当前选中的 provider,「连接 / 模型 / 参数」三个薄页签把长内容切成三屏,不再有任何行内展开。点左栏切换试试。

案二

登记卡 · 总览 + 专注页

第一层是可扫读的卡片索引:每张卡只回答「连上没有、用的什么模型、是不是默认」,常用操作(启停、设默认)直接在卡上。点「配置」进入第二层专注页——左列连接与参数、右列全高模型列表,一屏放下全部内容。点卡片可切换两层。

案三

模型总账 · 以模型为中心
