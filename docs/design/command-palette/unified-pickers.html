Composer 浮层 · 统一行语法

File / Skill / Command 三个 picker 本来就渲染同一个 ComposerExtensionPanel, 行结构也一直是同一套三段式。分裂只来自 CommandPicker 多传的那个 variant="command"。 下面是删掉 variant、把去线设计放进共享层之后的样子——一套语法,三种内容。

共享行语法

槽一 · 记号(可空) 槽二 · 名字 槽三 · 说明 槽四 · 附注 + ⏎
槽二定宽 152px = 软制表位:说明一律从同一条看不见的竖边起排。槽一留空时,名字直接贴 12px 左边距,不占位。 整块面板只有两条线:外框 + 提示条上沿。

Command —— 记号槽留空,附注=类型(仅选中行)

命令的类型不值得每行都占位,所以槽一空着、名字贴左边距,类型退到槽四且只在选中时露面。 对齐规则、字号、留白、选中样式与上面两个逐像素相同。

COMMAND17
/model 切换当前会话的模型 cmd⏎

/monitor 盯住一条命令直到条件满足再叫我 skill⏎
/move-session 把当前会话移到别的工作区 action⏎
/mock-data 按 schema 造一份假数据喂给测试 prompt⏎
