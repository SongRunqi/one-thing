方案 C

工作台 · 以活为脊 + 线程常驻

承认一件事:跟一群 agent 说话,本质是在盯一堆活。所以左栏的第一区不是"对话",是进行中的活 (卡片:名字 + 负责人 + 状态 + 进度),对话列表降到它下面。中栏是账页式消息流—— 左侧一条固定的署名列,每条消息一栏账,密度是四套里最高的(一屏 ~14 条)。 执行细节以活动线逐行列出(读了什么、改了哪一行),点右端"展开"在常驻右栏成线程。 权限审批也落在右栏,不再弹窗打断。这是 Slack / Linear 的形态:适合一个人同时盯 3–4 个 agent 干活。
