这一面上被拿掉的东西

  • TabBar header —— 房/私聊不再有页签。换房走左栏;房头只剩身份与动作。(直聊仍保留页签与分屏,那是工程面。)
  • ChatSidePanel —— 它的大纲/文件/引用并入右栏 tab 或房头动作,不再占中栏右侧一条。
  • 行内工具卡 / StepsPanel / diff / 图片生成卡 —— 全部只在右栏线程出现。
  • AgentSelector / 模型选择 / think 档 / ctx 量尺 —— 房里不出现:身份即房间,配置在空间页的「配置」tab。
  • GoalStatusBar / 大纲导航轨 / 练习条 —— 直聊的东西,不进房。
