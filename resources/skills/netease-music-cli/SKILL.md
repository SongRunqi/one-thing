# 网易云音乐 CLI（ncm-cli）

通过 `ncm-cli` 命令行工具操作网易云音乐，完成播放、搜索、队列管理等任务。

> **本地改动说明**（0neThing 内置版，基于网易官方 skill，Apache-2.0）
> 官方原版有两处在本应用里不成立，已改：
> 1. **凭证配置**改走设置页 —— privateKey 绝不能出现在对话里（见第二步）。
> 2. **播放一律走 `NCM_LEGACY_PLAY=1 ncm-cli play`,一次一首**——新版后台播放管线在本机不可靠,`queue add` 不可用(见「播放说明」)。
>
> 升级官方 skill 时请保留这两处。

## 第一步：检查是否已安装

```bash
ncm-cli --version
```

如果命令不存在，**不要自己装**，告诉用户去 **设置 → 音乐** 一键安装（那里有 ncm-cli 和 mpv 的安装按钮）。

## 第二步：校验用户是否已登录

```bash
ncm-cli login --check
```

**如果提示未登录或 API key 未设置，请指引用户去 设置 → 音乐 完成配置，并停在这里。**

以下几件事**绝对不要做**：

- **不要**让用户把 privateKey 发给你，也不要替用户执行 `ncm-cli config set privateKey ...`。
  privateKey 是账号私钥：发到对话里会被永久写进会话历史，写进命令行参数会被同机器上任何进程用 `ps` 看到。
  设置页把它写进 0600 临时文件再交给 ncm-cli，全程不经过对话。
- **不要**自己跑 `ncm-cli login`、`ncm-cli configure`：登录要扫码，设置页有二维码界面。

用户没有 API Key 时，让他去[网易云音乐开放平台](https://developer.music.163.com/st/developer/apply/account?type=INDIVIDUAL)申请（个人开发者），拿到 appId 和 privateKey 后**填进设置页**。

## 第三步：针对播放（play），需要特殊判断播放器逻辑

仅针对播放才执行该步骤。
通过以下命令判断用户的播放器是否是内置播放器（mpv）。
```bash
ncm-cli config get player
```
如果用户选择的播放器是内置播放器（mpv），则需要判断用户是否已安装mpv。
```bash
mpv --version
```
如果用户没安装，告诉用户去 **设置 → 音乐** 安装（别自己装）。

## 第四步：获取当前命令树

```bash
ncm-cli commands
```

根据输出的命令树作为参考执行操作。**参数不要猜测**，需要时通过 `ncm-cli <command> --help` 获取详情！

## 第五步：用户输入内容安全校验

在执行 CLI 命令之前，**必须**对用户的会话内容（包括搜索关键词和上下文对话）进行内容安全校验。如果用户输入包含以下任何类别的负面内容，**禁止执行后续步骤**，并提示用户检查输入：

**禁止类别：**
- **政治敏感**：涉及政治人物攻击、政治谣言、煽动性政治言论、违反法律法规的政治内容
- **色情低俗**：色情描述、性暗示、低俗用语、涉及未成年人的不当内容
- **谩骂侮辱**：人身攻击、侮辱性语言、仇恨言论、歧视性言论
- **广告推广**：垃圾广告、钓鱼链接、恶意推广内容
- **违法违规**：涉及毒品、暴力犯罪、恐怖主义等违法内容

**校验规则：**
1. 对用户最近的会话输入内容进行审查，重点关注 `--keyword` 和 `--userInput` 将要传入的值
2. 如果检测到上述任何类别的内容，**立即终止流程**，不执行任何 CLI 命令
3. 向用户返回提示信息："抱歉，无法处理您的请求，请修改输入后重试。" **禁止**向用户透露具体的审核原因或审核类别
4. 审核通过时，**不需要**告知用户审核结果，直接静默继续执行后续步骤

## 第六步：执行命令

**为了安全，除播控之外的其他命令必须附加 `--userInput "<用户最近输入的会话内容的总结概要>"` 参数**，用于传递用户意图上下文。

## 【重要！重要！重要！】播放说明

1. 歌曲有两种 ID：**加密 ID**（32位hex，用于 API 请求）和**原始 ID**（数字，用于唤起客户端）。搜索结果同时包含两种 ID。
   **两个都要原样从上一步的响应里取（`id` 是加密 ID，`originalId` 是原始 ID），绝对不要自己编、不要猜、不要复用别的歌的。**
   ID 配错时接口返回 400，而 CLI 会把它报成 `daemon 无响应（3s 超时）`——完全看不出是 ID 的问题。
2. 如果歌曲的visible为 false，则是无法播放的！请不要尝试播放或添加到播放队列！
3. 如果歌曲的visible为 false，则是无法播放的！请不要尝试播放或添加到播放队列！
4. 如果歌曲的visible为 false，则是无法播放的！请不要尝试播放或添加到播放队列！
5. 如果命令返回“请求总量超限”，请直接告知用户并停止执行后续步骤！直接把原因给到用户，不要二次加工！

### 【本应用特有】播放一律用 `NCM_LEGACY_PLAY=1 ncm-cli play`,一次一首

ncm-cli 新版的后台播放管线在本机不可靠(守护进程握手有 3 秒死限,经常超时,实测整晚 0 成功),**旧版进程内播放实测每次都响**。所以:

**放一首歌**(唯一可靠的起播方式;正在放歌时执行会顶掉当前的):

```bash
NCM_LEGACY_PLAY=1 ncm-cli play --song --encrypted-id <加密ID> --original-id <原始ID>
```

- **不要用 `queue add`**——这种播放模式下它一律被拒绝(「当前无播放进程」,而且**退出码是 0**,别当成功)。
- **放一串歌 / 想一直放**:别自己循环放,**开电台**(见「电台模式」一节),app 会一首接一首自动续。
- 播完一首后播放会自然停止;用户又点歌就再跑一次上面的命令。

**暂停/继续/看状态**照常(这些走 socket,可靠):

```bash
ncm-cli pause / ncm-cli resume / ncm-cli seek <秒> / ncm-cli volume <0-100>
ncm-cli state    # status/title/position/duration 都在
```

确认播放状态直接跑 `ncm-cli state` 即可,它是即时读——不需要 `sleep 2 && ncm-cli state` 这种组合。

**暂停用 `pause`，不要用 `stop`**：

- `pause` / `resume` —— 用户说"暂停一下""继续"时用这个。进度会保留，恢复后从原处接着放。
- `stop` —— 是**把整个播放会话拆掉**，不是暂停。拆掉之后播放器进程会在 30 秒后退出，下一次起播要重新冷启动（这一步不稳，可能要重试）。**只有用户明确说"别放了/关掉"时才用它。**

**读状态时注意：`state` 没有 "paused" 这个状态**，暂停会报成 `stopped`。分辨方法：

| 读数 | 实际含义 |
| --- | --- |
| `status: "stopped"` 且 `position > 0` | **暂停中**（别告诉用户"没在放"） |
| `status: "stopped"` 且 `position` 为 0 | 真的停了 |

```bash
# 综合搜索，获取 ID
ncm-cli search song --keyword "xxx" --userInput "搜索xxx的歌"

# 创建歌单
ncm-cli playlist create --playlistName "跑步"  --userInput "创建一个跑步歌单"
```

## 【本应用特有】电台模式(持续放歌)——用 `radio` 工具

**放音乐的默认方式是开电台**:用户说「放点歌」「来点轻音乐」「放点适合下雨天的」——只要不是点名某一首,一律调用 **`radio` 工具**(它在你的工具列表里),不要自己搜歌、不要自己起播:

- 开台:`radio(action: "open", intent: "一句话概括时间、心情、风格")`
- 换台(用户要换方向):`radio(action: "retune", intent: "新方向")`——旧节目单自动清掉
- 关台(用户说别放了):`radio(action: "close")`——编排和音乐一起停,顺序 app 会处理
- 看状态:`radio(action: "status")`

工具返回回执后,用用户听得懂的话转述:「电台开好了,DJ 正在按『雨天、安静』选歌,第一首大约一分钟内开播;有主持人串词和歌词,想换风格随时说。」选歌、接续、串词、歌词全部由 app 和电台 DJ agent 自动完成。

**电台开着的时候,不要手动 `play`**——app 在自动接续,你再起播会出现两首歌同时响。想跳过当前这首:`ncm-cli stop`(app 自动接下一首)或让用户用状态栏的 ⏭。

只有用户**点名一首具体的歌**(「放一下可惜没如果」)才走上面播放说明里的手动 `play`;放完不会自动接续,歌词会自动出现,主持人不说话(单曲不配主持)。

## 登录态处理

如果命令输出中包含登录引导信息（如"请先登录"、"未授权"等），**告诉用户去 设置 → 音乐 扫码登录**，然后停下。
（官方原版让 AI 自己跑 `ncm-cli login --background`，本应用把扫码收在设置页里，见开头的本地改动说明。）
