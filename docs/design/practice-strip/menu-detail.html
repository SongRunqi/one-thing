练习菜单 · 案二详设

总原则:菜单只放动词,设置全部住在练习 tab。菜单是"今天开始练"的一秒入口; 参数、分类管理、音效这些低频决定去 workspace 的练习 tab 里慢慢调——菜单末项「参数与账页 ›」一步直达。 菜单浮层复用 SessionContextMenu 族(圆角 10 / 纸面 / tooltip 影),点外或 Esc 收起,支持 ↑↓ + 回车。

① 菜单 · 默认态 四个动词 + 一个去处

每项 = 动词开头 + 右侧灰字参数回显。灰字只是"回显"当前设置,不可点——想改就去末项。

回显灰字来自 config,始终反映当前参数,点了不生效 音效唯一留在菜单里的开关——练之前顺手切静音是高频动作 直达「参数与账页」打开 workspace 练习 tab,菜单收起

② 番茄 · 二级分类 选中即开始,不再确认

hover「开始番茄」滑出分类子菜单;点分类立刻起番茄并关菜单。回显里的默认分类(上次用的)排第一,直接点主项 = 用默认分类开始,熟练后一次点击。

③ 补录 · 菜单原地变身 不跳走,一行输入回车即记

点「补录一笔」,菜单体原地换成一行输入(宽度不变、位置不动),回车落账、显示「已记上」后自动收起;Esc 退回菜单。语法照旧:名称 + 组×次 或 分钟。

④ 运行中点隐线 · 控制菜单 头部报进度,动词只剩两个

运行中隐线本身是进度指示(墨段收放/着墨);点它弹的菜单换成控制形态:头部一块进度区(相位大字 + 次数/组数),下面只有 暂停/结束 和「查看进度 ›」。结束会如实落账(中途也记)。

⑤ 设置的家 · 练习 tab 参数区 低频决定,给足空间慢慢调

workspace 练习 tab 顶部加一块「参数」区(账页保持在下方):凯格尔四个数字就地点改、 番茄时长 + 分类管理(点 × 删、虚框加)、音效开关。菜单「参数与账页 ›」和账页里任何入口都到这里。 不进设置页——这是练习数据的一部分,不是应用配置。

⑥ 细则一页 实现口径

锚定:菜单从隐线正下方垂下(top: 基线 + 6px,水平居中于墨段),纯浮层(absolute,z 同 tab-more-menu),聊天布局零变化。
键盘:↑↓ 移动、回车执行、→ 进二级、Esc 逐级退出;打开时焦点落第一项。
收起:点外(pointerdown capture)、Esc、任一动词执行后。
回显数据:hint 全部来自 practice config,菜单打开时即时读取,不缓存。
状态机:idle → 默认菜单;running → 控制菜单;paused → 控制菜单(「暂停」变「继续」,隐线墨段静止半透明)。
迁移:现有抽屉整体删除;PracticeStrip 保留 seam 与运行态,新增 PracticeMenu 子组件; 调参 UI 从抽屉移到练习 tab 参数区(PracticePanelContent 顶部新 section,写 practiceSetConfig)。
