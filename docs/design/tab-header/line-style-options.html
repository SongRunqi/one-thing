Tab Header · 画线三案

chat 窗口顶栏的三种画线语言,彼此截然不同。共同约束:控件一律 28px 高、同一水平线; 无胶囊无底色;agent 选择器与按钮同排;简洁大方。

A 把状态画在一条基线上;B 全场无线,只用括角与标点;C 用报头双线压阵,圈点记当前。

A · 座标底线

Baseline — 状态是基线上的墨段

整条 header 只有一条通栏基线。当前 tab 在基线上描一段朱砂实线,悬停浮现点线段 —— agent 与图标按钮也一样落线。承 side panel 书目的「点描实」句法,是现状的完成态。

B · 括标

Brackets — 无线,记号即结构

整条 header 没有一条横线。当前 tab 被一对朱砂括角「 」抱住(左上/右下,呼应工具面板的角标), 组与组之间只用一枚中点「·」。最空、最静,纸面完全不被划开。

C · 眉栏

Masthead — 报头双线,圈点记当前

一对细双线把眉栏压在纸面之上(报头/书眉传统)。tab 是衬线栏目字, 不用图标,当前栏目由一枚朱砂圈点记出(与 side panel 节头同一记号);agent 选择器是右端的落款。

A · 座标底线

  • 通栏基线 1pxheader 与纸面的界
  • 朱砂实段 = 当前悬停为点段,点描实句法
  • 竖刻分组chat 组 / 资源组 / agent 与按钮之间

B · 括标

  • 零横线纸面不被划开,最静
  • 朱砂括角「 」= 当前左上右下两只角,呼应台面角标
  • 中点「·」分组标点当结构,排版传统

C · 眉栏

  • 细双线压栏报头传统,眉栏自成一件
  • 朱砂圈点 = 当前与 side panel 节头同一记号
  • 衬线栏目字 + 落款不用图标,靠字面身份
