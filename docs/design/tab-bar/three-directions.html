Tab Header · 三向重构

三案不是三种皮肤,是对「页签是什么」的三种回答:案一说页签是弹性的书签,案二说页签是书口的刻度,案三说页签根本不该占一条横条。每案都必须正面回答下面三条病历。

① 不弹性tab 定死 min-width 82px、icon/close 永久占格,空间不随分屏收缩,只能整条塌缩。
② 黑圆点「已缓存」小黑点几乎人人都有 —— 常态信息不该用点状徽记,视觉上像满页污渍。
③ 分屏挤右侧五粒按钮 flex-shrink:0,窄面板里 tab 与按钮互相顶撞,540px 以下功能直接消失。
案一

弹性墨签 · 等分共享,阶梯降级

保留横向页签,但换成真弹性:flex: 1 1 0 等分共享整条,收窄时一起变短;关闭钮悬浮在右缘纸色渐变上,不再永久占格。空间不足时走三级阶梯:全签 → 非激活签缩成图标 → 动作组收进一粒「⋯」。缓存点删除:冷会话(未入内存)用虚描图标表示,常态(已缓存)反而无标记。

① 弹性

flex:1 1 0 等分共享;close 悬浮不占格;窄档非激活签自动缩成 34px 图标位。

② 圆点

删除。缓存是常态,常态无标记;冷会话才用虚描图标示意「点开要重新载入」。

③ 分屏

按钮组按优先级折叠进「⋯」,任何宽度下 tab 与核心动作都活着,不再整条塌缩。

代价:改动最小、心智不变;但 tab 一多标题仍会互相挤短,本质仍是「一条横杆分给所有人」。

案二

书口刻度 · 只有当前页摊开,其余收成刻痕

像合上的账本:书口一侧只看得到一排检索刻痕。激活页签独占标题,非激活页签收成 26px 的一道竖刻,悬停时向右抽出标题、点击翻页。缓存态直接编码进刻痕笔法 —— 实刻 = 驻内存,虚刻 = 冷会话,青刻 = 未存档文件,圆点的信息并进了线里。N 个 tab 的成本 ≈ N × 26px + 一个标题,分屏天生不挤。

① 弹性

结构性解决:只有一个标题需要宽度,其余固定 26px。tab 数量翻倍,占宽只加一指。

② 圆点

点的信息升维成刻痕笔法:实/虚/彩三种线型,状态可读且属于画线语言本身。

③ 分屏

420px 面板放五个 tab 仍有余量,按钮组不必抢地,紧凑模式阈值可大幅下调。

代价:非激活标题不可见,认 tab 要靠悬停或记位置;多 tab 重度用户需要适应期。刻痕需要 ≥8px 命中区外扩。

案三

卷首行 · 取消横签,标题即页签

最激进:整条 bar 不再陈列 tab。当前会话标题作为卷首写在左侧,配一个「之二 / 五」的账页计数;点击标题摊开竖排账页列表 —— 每个 tab 一整行,标题永不截断,状态(驻内存/冷)作为右栏小字。横条上永远只有一行字 + 按钮,分屏窄到 300px 也不会挤。

① 弹性

横条上只有一个 min-width:0 的标题在伸缩,弹性问题连同 tab strip 一起消失。

② 圆点

状态成为账页列表的一栏小字(冷 / 未存档),有名有位,不再是挂在标题上的污点。

③ 分屏

每个面板固定成本 ≈ 标题 + 计数 + 两粒按钮,320px 仍然完整,紧凑模式可以整个删掉。

代价:切 tab 从一步变两步(⌘1-9 / ⌘⇧[] 快捷键必须补位);「有哪些 tab 开着」不再一眼可见,靠计数提示。拖拽分屏交互需改成从列表行拖出。
