InputBox ModelSelector — 四方案对比

输入框模型 chip 弹出的选择器,popover 与 InputBox 同宽自适应(页内可切 360/640/900 验证);能力用图标+文字徽章、flex-wrap 换行展示,不遮挡不溢出。全部走 --ui-* 主题 token(Flexoki 深/浅演示值,页内可切换);选定方案后替换 ModelSelector.vue 的 Select 下拉即可接入。

E图纸原生 Blueprint(贴合当前 InputBox)
与现有 composer 完全同一视觉语言:MODEL 框签切轮廓、hairline 分段单元格、mono 标注;flyout 锚定 composer 顶边同宽;行样式沿用现有 dropdown 字号,能力徽章沿用 .model-badge 几何但按能力着色 + 换行。demo 里连 composer(COMPOSER 框签 + 工具条 ctx 表计/think/mode/SEND 格)都按 InputBox.vue 逐项复刻。
推荐:接入成本最低,视觉零违和 — 相当于给现有 Select 下拉升级为蓝图 flyout。
A层叠菜单 Cascade
原生菜单式二级层叠:provider 一级菜单,悬停右侧展开模型子菜单(底边跟随悬停项),单击即切换。零搜索、路径最短。
适合:provider 多、靠位置记忆快速切换;最像系统原生菜单。
B速查单列 Compact List
324px 可搜索单列(Linear/Cursor 式):搜索置顶,模型按 provider 分组平铺,一次滚动看全;能力微型色点,↑↓/↵/esc 键盘可达。
适合:模型总量大、键盘流;与现版 Select filterable 的心智最接近。
C图标页签 Icon Tabs
顶部一排 provider 图标页签(当前 provider 带角标),中部该 provider 模型列表(能力字母 T/R/V/I/S + 上下文),底部常驻当前模型状态条。
适合:provider 维度优先、鼠标两击切换;信息密度均衡。
D下钻两屏 Drill-down
300px 窄面板,移动端式二级导航:第一屏 provider 大行(显示 using 哪个模型),点击滑入第二屏模型列表,‹ 返回;esc 逐级退出。
适合:界面最克制、视觉负担最小;provider 行自带"正在使用"上下文。
