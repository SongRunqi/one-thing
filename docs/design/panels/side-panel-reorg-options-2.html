Side Panel · 重组方案 第二批

与第一批(检字/案头/批注边)完全不同的三种组织逻辑:按时间合流、只显当下、空间随注意力流动。这一批收掉装饰性隐喻,走朴素直接的信息整理。

肆

编年 · 一条时间流,不再分区

UNIFIED LEDGER

换一个根本假设:目录和待办本来就是同一条时间线上的事件——「聊到了什么」和「做完了什么」交替发生。所以面板不分区,只有一条编年流:轮次、小节标题、任务完成,按发生顺序排在同一根脊线上,靠四种记号区分(○ 轮次 · 小节 ✓ 已讫 ● 进行中)。还没发生的任务排在流的末尾。提示词只在卷首留两行题记。

得:没有节头、没有分割条、没有折叠——整个面板只有一种结构,读起来像看一份会议纪要;「做了什么」自带上下文(它发生在哪个话题里)。失:想单独看「全部待办」需要扫全流(靠记号颜色补偿);事件与话题的归属需要引擎记录时间戳。改动:中——数据侧要把 todo 事件挂到轮次上。

仪表 · 只显当下,永不滚动

COCKPIT

反向做减法:面板不再试图「陈列全部」,只回答三个瞬时问题——我在哪(当前小节,前后各露一行,随聊天滚动自动跟随)、做到哪(大数字进度 + 当前任务一句话)、环境是什么(模型/字数/工具/skills 四格读数)。固定高度,永远放得下,永远不滚动、不折叠、不截断。要看全量?点「我在哪」跳回正文,点环境读数打开既有的设置对话框——聊天区本身就是详情页。

得:面板彻底安静,信息密度降到「一眼读完」,再长的会话也不变重;跟随滚动让它变成实时仪表而非静态档案。失:失去浏览能力——不能在面板里翻历史小节和任务清单;依赖「点击跳转回正文」这条路径成立。改动:小——只做当前位置追踪,其余全是删。

呼吸 · 三段同显,空间随注意力流动

ELASTIC FOCUS

保留「三块同时可见」,但废掉三等分和一切折叠钮/分割条:未聚焦的段落自动压成一行「活摘要」——不是干巴巴的节头,而是各自最要紧的那句话(目录压成当前小节,待办压成 4/7 + 当前任务,提示词压成模型 + 字数)。鼠标移到哪段,哪段自然长开占据大部分高度,其余让位。没有任何点击操作,空间自己呼吸。把鼠标移到下面面板的三段上试试。

得:三块永远在场且摘要本身就有信息量,展开零点击;去掉全部折叠/拖拽控件后视觉噪音大减。失:悬停驱动的布局变化需要克制的动效调校,否则会晃;触控板误触边缘时会有轻微重排(可加短延迟)。改动:中——布局层重写,三个子面板内容复用。
