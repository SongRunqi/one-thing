命令面板 · 画线风四案

InputBox 里键入 / 唤起的 command / skill / prompt 选单。四案共用同一份数据 —— 查询 “co”,选中第二项 /commit —— 只有结构语言不同:横格、坐标纸、校对稿、单线谱。

案一 · 账页横向红格 + 点线引导,条目是账上的一笔

每行落在一条格线上;左侧装订线隔出类别栏,标题与描述之间用点线牵引。选中即“记账”:类别提红、名目加粗、行尾落 ⏎。

案二 · 制图坐标纸 + 角部规线 + 尺寸标注,选单是一张图纸

底衬细坐标格,四角伸出十字规线;条目带件号,类别写成 [标注]。选中项右侧拉出尺寸括线标 ⏎,页脚是四格图签栏。

案三 · 校雠校对稿 + 页边符号 + 绿笔圈点,选中即批注

衬线排版,条目像稿纸上的一行行文字,页边留校对符(〇命令 △技能 ◇提示词)。选中项被绿笔手绘一圈,命中字符走双下划线。

案四 · 线谱一根竖线贯穿到底,条目是线上的站点

整个面板只画一根线:每个条目在线上刻一道站点,悬停刻痕伸长,选中处结成空心圆。线的末端收一个箭头,指向快捷键提示。
