案一 · 独木减法 / one line

基线上只许一条线说话。删掉浮层滚动条——边缘渐隐已经承担了「后面还有」; 练习条下移,不再反向侵入基线带。基线 = hairline,激活段在其上着墨。

取舍:最克制,一眼干净。代价是失去滚动位置感——只知道「还有」,不知道「在哪」。 改动最小(删已有滚动条 + 练习 top 下移)。

案二 · 分道lane separation

信息全保留,靠垂直错位分开。滚动条移到 tab bar 顶边,与基线彻底不相干; 基线归激活下划线;练习独占下方一带。三条线各占一道。

案三 · 同轨时分复用 / one rail, many roles

基线是唯一的一条「轨」,不同状态在同一条轨上换角色,绝不叠加: 静止 = hairline + 激活墨段;滚动中 = 轨道局部变滚动条;练习运行 = 轨道左端填充进度。

取舍:最合画线风,一条线承载三种语义,信息零损失且永不叠压。 代价是滚动/练习时激活下划线被临时顶替,需要另找方式标记选中(如加深字色);状态机也最复杂。

案四 · 换语汇non-line encoding

从根上断绝竞争:只有「选中」配用线。其余信号一律改用非线语汇—— 滚动用边缘渐隐 + 尾部计数,练习进度改成右侧点阵刻度 + 时间,把手改成一粒小三角。
