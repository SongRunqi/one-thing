命令面板 · 去掉类型列

问题:cmd / skill / action / prompt 这条固定列在 620px 的 composer 里吃掉 52–62px 加一条竖装订线,每一行都付这个钱,换来的却是你扫一眼就知道的信息。 下面先看它有多贵,再看三种不花这笔钱的办法。名字一律从左边距 12px 起排,描述吃掉全部剩余宽度。

类型只在选中那一行露面

未选中的行只有名字 —— 说明,一个字都不多。类型退到行尾,只有你真正停在某条上时才浮出来, 跟 ⏎ 一起出现。要判断类型的时刻,恰好就是你已经选中它的时刻。

每行回收 64px · 描述可见长度 +38%

类型压成一个字符的记号

类型不写字,只留一个 11px 宽的记号:/ 命令、◇ 技能、 ▸ 动作、¶ 提示。类型信息一直在场(扫一列记号就能分辨), 但成本从 64px 降到 20px。代价是记号要认,新用户头几次得猜。

每行回收 44px · 类型信息 全程可见

类型退成分组小标题

类型说一次就够,不必每行重复一遍。同类的条目排在一起,顶上一行 mono 小标题带一条延伸线—— 跟框标签是同一支笔。横向 100% 还给内容,只在纵向为每个出现过的类型付一行。
