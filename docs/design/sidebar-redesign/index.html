Sidebar 六方案

同一份真实内容(session 分组、电台组、生成中状态、五个 workspace 入口 + 设置)在六种截然不同的性格下的呈现。 每个方案都是完整可用的,差异在气质与信息组织方式,不在功能取舍。

方案一

呼吸 · 纯排版

零线条、零底色、零图标修饰 —— 层级完全由字重、灰度和留白表达。 当前会话只有一枚悬挂在文本外的墨点。最安静的一版,适合把注意力全部留给聊天区。

方案二

岛屿 · 双栏结构

唯一动结构的方案 —— workspace 入口从底部横排搬进左侧 52px 竖向 rail, 新会话置顶、设置沉底,session list 独占整列纵深。工具感最强,入口永远一眼可见、不与列表争夺滚动空间。

方案四

目录 · 杂志编辑部

唯一带内容摘要、唯一全文字无图标的方案 —— 每条会话是"标题 + 最后一句话 + 时间"的目录条目, 衬线标题、双粗线框定版面,底部入口直接用汉字。会话列表从"文件名列表"变成"可浏览的刊物目录"。

方案五

时间轴 · 一条线

唯一以时间为第一叙事的方案 —— 一根贯穿全列的细线把所有会话串成节点, 日期戳骑在线上,当前会话是实心大节点,生成中的节点向外扩散波纹。会话史读起来像一天的工作日志。
