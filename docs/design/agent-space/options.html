四案对比 · Agent 空间

点开一个人之后,那一面长什么样

四案共同的地盘不变:头像可点、不跳 Agents 管理页、配置就地改、会话行去主区页签、文件行去右栏文件页签。 差别只在那一面的信息架构:分面切换 / 一页长卷 / 主区档案页 / 上下常驻。 四案用的都是项目现有的类(样式段注明出处),颜色字号是 variables.css 真解出来的, 每案末尾标了它自己要新写多少 CSS 与多少逻辑。

切一下看主题跟随
案一句话导航层数一屏能同时看到占不占主区代价

三 · 档案页在主区开"这个人"的页签1(页签即那一面)配置全表 + 账目全栏占一个主区页签 新 CSS 6 条 · 要给主区 tab 模型加 kind
四 · 上下常驻右栏切两段,上人下账1(两段都在)配置 + 账目同时不占 新 CSS 6 条 · 无新机制
