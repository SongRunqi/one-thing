练习条 · 展开态六案

两个待解问题:① 展开不得推动聊天布局(现抽屉占文档流 40px);② 展开态要一眼看懂 (现在一行字混排三种功能)。六案在"展开到哪里去"这个机制上截然不同; 静默态与运行态维持已实现的隐线不变。每帧下方的灰字聊天示意保持原位,即为"布局未被推动"的证据。 已排除的方向:往下推但加动画(位移仍在,治标)、hover 展开(误触且不可发现)、独立小窗(此前已否)。

案一 · 浮批 从隐线垂下的浮层账卡,覆盖而非推挤

点隐线,一张 480px 账卡从基线垂下,浮在聊天上方(纸面 + 细边 + 薄影)。三行名目左对齐: 凯格尔 / 番茄 / 补录,每行"名目 → 参数 → 动词"从左到右一条视线。点卡外或 Esc 收回。 它是现方案的直系修正:交互位置不变,只是从"占行"改成"浮层",并给了内容呼吸的空间。

案二 · 墨签菜单 就是一个右键菜单,零学习成本

展开态直接复用应用现有的菜单族(SessionContextMenu 同款圆角纸面):竖排四项, 每项"动词开头 + 右侧灰字参数提示",番茄的分类走二级菜单。菜单是最被普遍理解的控件—— "什么是什么"由控件惯例回答,不需要用户学。参数修改不进菜单(去练习 tab 改),菜单只管"开始"。

案三 · 换幕 tab 栏原地变身练习栏,不新增一像素

点隐线,40px 的 tab 栏自身"换幕":页签淡出,练习控件淡入,同一行内用竖刻分隔三个组, 右端 × 返回。没有浮层遮挡聊天,也没有任何新增高度——它借的是已经存在的空间。 一行的排布密度约束仍在,但整行都是练习的了,比旧抽屉从容一倍;有"进入练习模式"的仪式感。

案四 · 命令行 不造新面板:点隐线 = 打开预过滤的命令面板

隐线只是一个触发器:点击打开命令面板并预过滤到练习命令(/kegel、/pomodoro、补录)。 每条命令自带一整行的说明文字——"怎么用"由面板的账页行回答,且键盘直达。 练习不再拥有自己的展开面板,系统里少一个要学的东西;代价是每次开始多一步确认(回车)。

案五 · 工作台直达 点隐线 = 打开练习 tab,启动区搬进宽面板

展开态整个取消:点隐线直接打开右侧 workspace 的练习 tab,启动/调参/补录都住在那里, 有整面板的空间做清楚的卡片和表单——"什么是什么"用空间和层级解决,不用密度换。 聊天宽度变化走的是 workspace 面板的既有弹性动画,是应用里已被接受的行为,不是布局跳变。 隐线自身退回纯指示器(运行进度),职责最干净;代价是快速开始要"跨一个面板"。

案六 · 仪式卡 居中登台:开始练习是一个郑重的动作

点隐线,画面中央升起一张三栏卡(Search Everywhere 同族的浮窗),背景轻压暗。 凯格尔 / 番茄 / 补录各占一栏,竖刻分隔,宋体标题领起,每栏参数完整可改、动词唯一。 六案里"看懂"做得最彻底的一案——空间最奢侈、层级最清楚;也最重,适合把"开始练习" 当作一次切换心境的仪式,而不是顺手一点。
